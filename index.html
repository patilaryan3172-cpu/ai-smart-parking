A* Search Algorithm

Used to compute the shortest walking path from the assigned parking slot to the building entrance through walkways.

f(n) = g(n) + h(n)
  • g(n) — actual cost from start to node n (walked distance)
  • h(n) — heuristic estimate from n to goal (Manhattan distance)
  • f(n) — total estimated cost used for priority queue ordering

The algorithm explores walkable cells (walkways, entrance, gate) and avoids walls and occupied slots. The resulting path is visualized on the Live Parking Map.

Constraint Satisfaction (CSP)

Vehicles are assigned to compatible parking slots by solving a CSP:

  • Variables: vehicles requiring parking
  • Domains: eligible parking slots based on vehicle type
  • Constraints: slot size compatibility, accessibility, EV charging, unique assignment

Backtracking with forward-checking prunes invalid domains early, ensuring no two vehicles share the same slot.

Rule-Based Reasoning Engine

Translates vehicle attributes into parking requirements before CSP solving:

Size Rules
  • Motorcycle / Compact → compact or larger slots
  • Sedan → medium or large slots
  • SUV / Van / Truck → large slots only
Special Rules
  • Accessible permit → accessible slot required
  • EV → EV charging slot required
  • Non-EV → avoid EV slots when possible

Project Introduction

SmartPark AI is an intelligent parking allocation and navigation system built as a college AI micro project. It demonstrates how classical AI techniques — A* search, Constraint Satisfaction Problems, and rule-based reasoning — can be combined to solve real-world parking management problems.

Problem Statement

Urban parking lots suffer from congestion, inefficient space utilization, and driver frustration. Finding an available slot, especially one matching vehicle size or accessibility needs, wastes time and fuel. Existing systems often lack intelligent allocation and navigation.

Objectives

  • Automate parking slot allocation based on vehicle type and needs
  • Enforce accessibility and EV charging constraints
  • Compute optimal walking paths using A* search
  • Provide a real-time dashboard and interactive parking map
  • Demonstrate AI algorithms in a practical, working application

Proposed Solution

A web-based system where a rule engine interprets vehicle attributes, a CSP solver assigns compatible slots, and A* computes the walking route to the entrance. All data is persisted in SQLite and visualized through a modern responsive dashboard.

Advantages

  • Reduces driver search time through intelligent allocation
  • Respects accessibility and EV charging requirements
  • Provides optimal walking routes using A*
  • Real-time visualization of parking status
  • Scalable architecture for larger parking facilities

Limitations

  • Simulation-based — no real IoT sensors or cameras
  • Single parking lot (not multi-location)
  • No payment integration or user authentication
  • Static layout (not dynamically configurable)

Future Scope

  • Integration with IoT sensors for real-time slot detection
  • Mobile app with turn-by-turn navigation
  • Machine learning for demand prediction
  • Multi-level and multi-lot support
  • Payment gateway and reservation system
